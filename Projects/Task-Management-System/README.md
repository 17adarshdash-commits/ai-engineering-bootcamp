# Task Management System

## Description

A feature-rich command-line task manager that helps organize and track tasks efficiently.

## Features

- Add tasks
- Update tasks
- Delete tasks
- Search tasks
- Filter tasks
- Sort tasks
- Export to CSV
- Backup task data
- Generate reports

## Technologies Used

- Python
- CSV
- File Handling

## How to Run

```bash
python task_management.py
```
