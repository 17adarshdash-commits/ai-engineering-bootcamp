# Expense Tracker

## Description

A command-line expense tracker that stores expenses and generates reports.

## Features

- Add expenses
- View all expenses
- Calculate total spending
- Save data to a file
- Generate expense reports

## Technologies Used

- Python
- File Handling

## How to Run

```bash
python expense_tracker.py
```

## Skills Practiced

- File Handling
- Lists
- Dictionaries
- Functions
