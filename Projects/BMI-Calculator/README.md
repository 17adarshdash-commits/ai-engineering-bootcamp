# BMI Calculator

## Description

A Python command-line application that calculates Body Mass Index (BMI) and classifies the user's health category.

## Features

- Accepts height and weight
- Calculates BMI
- Displays BMI category

## Technologies Used

- Python

## How to Run

```bash
python bmi_calculator.py
```

## Skills Practiced

- Input Validation
- Mathematical Calculations
- Conditional Logic
