# Library Management System

## Description

A command-line library management application for managing books and borrowing records.

## Features

- Add books
- Delete books
- Search books
- Borrow books
- Return books
- Save data to files

## Technologies Used

- Python

## How to Run

```bash
python library_management.py
```

## Skills Practiced

- Dictionaries
- Lists
- File Handling
- CRUD Operations
