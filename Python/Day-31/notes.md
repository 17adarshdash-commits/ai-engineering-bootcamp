    - Recursion is a programming and problem-solving technique where a function calls itself to solve a problem by breaking it down into smaller, more manageable subproblems.
    Recursive Function: A function that contains a self-invocation within its own code block to repeat actions without using traditional loops.Base Case: The mandatory stopping condition in a recursive function that directly returns a value without making any further self-calls.Recursive Case: The section of the function that executes the self-call using modified, smaller arguments to actively move closer to the base case.Recursive Thinking: A logical approach that solves a large problem by breaking it into identical subproblems and combining their trusted, smaller solutions.

3. Base Case
Explain:
Why it is required
Infinite recursion
Stopping condition
    - Recursion is a programming technique where a recursive function repeatedly calls itself with smaller inputs during a recursive case, allocating distinct memory blocks called stack frames onto a call stack via nested function calls. This process relies on recursive thinking to break down a large problem into simpler tasks until a mandatory stopping condition—known as the base case—is reached. Once triggered, it prevents infinite recursion and a fatal stack overflow by successfully returning from recursion, systematically popping frames off the stack to calculate the final answer.

4. Recursive vs Iterative

When to use recursion
    - Recursion is often more readable than iteration when traversing complex hierarchical structures like trees or graphs, but it consumes significantly more memory due to accumulating stack frames and generally suffers from slower speed due to function call overhead, making iteration the preferred choice for linear tasks where performance and strict memory limits are critical.

5. Common Recursive Problems
Examples:
Factorial

Tree Traversal (preview)
    - Factorial: A classic example that multiplies a number by progressively smaller integers (\(n \times (n-1)!\)) until it hits the base case of one.
    Fibonacci: A sequence where each number is generated by adding the results of two recursive calls to the preceding two terms in the series.
    Sum of N numbers: A linear process that accumulates a total by recursively adding the current number to the sum of all preceding integers down to zero.
    Reverse String: A transformation algorithm that strips the first character of a string, recursively reverses the remaining substring, and appends the stripped character to the end.
    Tree Traversal (preview): A structural navigation method that cleanly visits every node in a branching data structure by recursively repeating the same logic on the left and right subtrees.
