    - Object-Oriented Programming (OOP) is a programming paradigm centered around "objects" rather than actions or logic. These objects represent real-world entities containing data (attributes) and code (methods).

    - In Object-Oriented Programming, variables defined inside a class operate at two completely distinct levels: the instance level (unique to each object) or the class level (shared by all objects).

What encapsulation means

    - Encapsulation is the process of bundling data (attributes) and methods into a single unit (a class) while restricting direct access to some of the object's components. It acts as a protective shield that prevents external code from accidentally modifying internal data, enforcing control through an authorized interface.
